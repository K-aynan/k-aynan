## 🚀 What I'm Building

### ⚡ Khorion

**Workflow orchestration infrastructure designed around reliability, observability and extensibility.**

Khorion is my main engineering project and the place where I explore concepts beyond conventional CRUD applications.

The system is being designed around concepts such as:

* asynchronous workflow execution
* event-driven architecture
* task queues and workers
* idempotency and deduplication
* retries and failure handling
* workflow versioning
* audit trails and execution timelines
* API contracts
* observability and diagnostics
* modular service architecture
* AI-assisted workflow tooling

**Current ecosystem**

`FastAPI` · `PostgreSQL` · `Redis` · `RQ` · `Docker` · `Alembic` · `Pytest`

> The goal isn't only to make workflows execute — it's to make their execution **predictable, inspectable and reliable**.

## ⚙️ How I Like to Build Software

I care about more than making something *work*.

I try to understand what happens when:

```text
the request is duplicated
        ↓
the worker crashes
        ↓
the database becomes unavailable
        ↓
the same event arrives twice
        ↓
a dependency starts timing out
        ↓
the system needs to explain what happened
```

That naturally pushed my interests toward **distributed systems, backend architecture, testing and observability**.

My engineering approach increasingly revolves around:

**small components · explicit contracts · strong tests · observable execution · controlled failure modes**
